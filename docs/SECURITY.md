# 安全性・プライバシー

2026-10-15：CLI＋トレイへ移行。確認はCLIのプレビューと[y/N]、またはトレイの取消既定ダイアログで行う。CLIと常駐間はCurrentUserOnlyの名前付きパイプ（同一セッション、demo別名）を使い、許可動詞だけを処理する。確認後の状態比較、長さ制限、切断時の取消を維持し、シェルや任意コマンドは受け付けない。

WinHTTPは設定読取りと利用者が明示したURLへのHEAD診断に限る。設定の書換え・WinINetとの同期はしない。診断先への通信とOSのPAC/WPAD解決は実行前に説明する。既定の外部接続はなく、認証・Cookie・リダイレクトの自動処理と証明書例外を設定しない。既存の禁止事項は維持する。

## 権限と対象

アプリは asInvoker で通常のログオンユーザーとして動く。管理者権限の要求、サービス登録、SYSTEM の使用はない。操作対象はそのユーザーの標準プロキシ設定と、自らのローカルデータ、任意のログイン時起動登録だけ。プロキシ設定 API はブラウザーなどの動作へ影響するので、一般権限でも影響の大きい操作として確認・記録・復元を行う。

Windows ポリシーによる変更禁止、マシン単位への切替等の既知の設定を検出したら拒否する。ブラウザーの独自ポリシーがある場合は対象差を通知する。全管理製品・GPO・MDM の設定を網羅しているとはしない。**ポリシーを解除したり、権限を上げて回避しない。** 標準 API の失敗も尊重し、エラーを説明する。[S06](SOURCES.md#s06-policy)

## 信頼境界

| 情報 | 信頼上の扱い |
|---|---|
| SSID / ネットワーク名 / NLM ID | 利便性の識別ヒント。組織の証明・安全なネットワークの認証ではない |
| プロキシ接続先 / PAC URL | 利用者が所属組織等の信頼できる指示に基づいて設定する |
| PAC スクリプト | Proxyz はダウンロード・実行しない。設定後の OS/アプリの動作は別 |
| ローカル設定ファイル | 同じ Windows ユーザーは編集可能。改ざん耐性を保証しない |
| 組織の管理制限 | 利用者設定より優先し、回避しない |
| 別アプリの書き込み | Proxyz の所有とは見なさず、内容差を検知したら自動上書きしない |

同名 SSID の偽装は防げない。NLM ID を組み合わせても暗号学的な本人確認にはならない。SSID による自動適用の限界をルール編集で表示する。ネットワークが安全だから証明書を信頼する、といった処理はしない。

## 保存するデータ

平文のプロキシ/PAC URL、除外先、メモ、ネットワーク名/ID、SSID 生バイト、復元用の Windows 設定。パスワード入力欄はなく endpoint の userinfo は拒否するが、組織の URL の query などに秘匿トークンが入る場合はある。データフォルダーと `.bak` を公開しない。ディレクトリはユーザープロファイルの通常のアクセス制御を継承し、独自の暗号化や資格情報保管庫は使用しない。

ログに URL / SSID / 設定の本文を記録しない。操作名、成否、日時、必要なプロファイル ID だけを限定サイズで記録する。画面の詳細エラーには Windows/ファイルパス等が含まれ得るため、外部共有前に確認する。ユーザー情報を自動で送信しない。

## 起こり得る故障への対応

| 故障 | 実装した抑止 |
|---|---|
| 保存先満杯/アクセス拒否 | 意図記録が保存できなければ OS を変更しない |
| 設定適用/通知/読み戻し失敗 | 可能な範囲で Before に戻し、成否を記録 |
| 最終ジャーナル保存失敗 | 元に戻すか、復元待ちを維持 |
| 適用中に外部変更 | 別の値を検知したら無理に上書き/復元しない |
| プロセス強制終了/電源断 | Pending を次回起動で検出。確認なしに再試行しない |
| 通知により失敗処理が繰り返される | 同一ネットワークでの自動失敗をラッチして抑止 |
| 読めない設定/将来 schema | 上書き/初期化せず起動エラー |

ジャーナルは Windows の設定とディスクをまたぐ分散トランザクションではない。OS 書き込みの最後の瞬間の競合、ストレージの物理故障、同一ユーザーによる改ざんを完全に防ぐものではない。安全性を増すためデモ→読み取り→明示許可後のテストの順を守る。

## Codex / 開発中の制約

ビルド、偽 OS テスト、構造体配置テスト、デモは通常の確認範囲。実プロキシ書換え、自動起動登録、位置情報許可、他アプリの終了、パケットキャプチャ、管理者権限操作は利用者に対象を説明して同意を得る。会社/大学のプロキシ/PAC/SSID を外部へ送らない。CI にユーザーの `config.json` を上げない。

## 削除とデータ整理

自動切替を停止し、必要ならプロキシを復元する。設定でログイン時起動を無効にしてからアプリを終了し、配布フォルダーを削除する。端末内データを削除する場合は、以後このアプリの履歴による復元ができなくなると理解してから行う。アンインストーラーはこのソース版に含めない。
