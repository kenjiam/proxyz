# アクセシビリティ仕様と検証表

**状態：アクセシビリティを考慮したコードあり。Windows/Narrator の実機検証は未実施。** 準拠認証や達成率を主張しない。第4段階で以下を受け入れ条件として確認する。

## 実装上の選択

標準 WPF Button、TextBox、ComboBox、ListBox、CheckBox、TabControl、Slider、Menu を使用する。全画面を Canvas やゲーム描画で描いて読み上げツリーを失う構成は採らない。Windows の標準コントロールと UI Automation を使うことは基礎であり、スクリーンリーダー実機テストを不要にしない。[S07](../../docs/SOURCES.md#s07-accessibility)

入力には可視ラベルと対応する Target / AutomationProperties.Name を設ける。ラベル名や状態は色だけで伝えない。主要な操作結果は live region、入力エラーは assertive live region とフォーカスで伝える。トレイ以外に同じ機能をメイン画面に置く。

Window / テキスト / 枠線は SystemColors の DynamicResource を使用。WPF の Light Fluent テーマを基本にし、コントラストテーマでの実際の色と可視性は確認する。独自の点滅/アニメーション、色のみに依存するトグル、消えるだけの通知は設けない。

## キーボード

| 操作 | キー |
|---|---|
| 画面切替 | Ctrl+1 / 2 / 3 / 4 |
| 最新状態を再確認 | F5 |
| ホームの手動プロファイル選択へ | Ctrl+M |
| フォーカス移動 | Tab / Shift+Tab |
| ボタン・チェック | Space / 表示されるアクセスキー |
| ダイアログ取消 | Esc / 取消ボタン |
| 主要項目 | ラベル・ボタンの Alt アクセスキー |

OS 設定を書き換える確認ダイアログでは「変更」を初期選択にしない。取消へフォーカス。保存の入力検証に失敗したらエラーへ移動する。背景の再読込で入力中の値や設定タブを勝手に戻さない。

## 拡大

PerMonitorV2 DPI awareness / WPF layout、TextWrapping、スクロール、可変フォントサイズを使用。アプリ内の追加倍率は1～2倍で、OS の倍率に上乗せする。基本のフォントはシステムの UI フォント。

**注意**：classic WPF の Windows「テキストのサイズ」への追随は、`HKCU\Software\Microsoft\Accessibility\TextScaleFactor` を読み取り専用で参照する互換性ブリッジを加えている。このレジストリ表現は将来互換性の契約された公開 API として扱わない。失敗時は SystemFonts とアプリの倍率を使用する。設定変更イベントによる反映、二重拡大、OS版ごとの差を第4段階で必ず確認し、必要なら公的にサポートされた適切な方法へ置換する。

## UI Automation の確認用 ID

| ID | 対象 |
|---|---|
| OperationStatus | 操作結果とエラー |
| AutomationState | 自動切替状態 |
| ProfileChoice / ProfileList | 手動選択 / プロファイル一覧 |
| RuleList | ルール一覧 |
| SavePreferences | 全般設定保存 |
| SaveProfile / SaveRule | 編集ダイアログ保存 |
| ConfirmAction | OS 変更の確認 |

読み上げ側の挙動は UIA ID があるだけで合格としない。Name、Role、Value、State、フォーカス、変更通知が意味を伝えるか確認する。
